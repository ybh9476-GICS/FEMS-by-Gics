# 화면 언어

설정에서 KOR / ENG / JPN을 선택하면 현재 화면과 이후 열리는 팝업의 문구가 바뀝니다. 최초 기본값은 한국어이며, 선택은 브라우저의 `fems-ui-language`에만 저장합니다. 프로젝트 데이터, `.fems` 형식, 자동 저장 키와 실행 취소 기록에는 언어를 넣지 않습니다. 로컬 주소와 GitHub Pages의 언어 설정은 각각 독립적입니다.

## 번역 범위와 이름 보존

- 화면 제목, 버튼, 도움말 본문·캡션, 툴팁, 접근성 설명, 검색 안내, 오류와 동적 숫자 문장을 번역합니다.
- FEMS, MCC, ESS, UPS, GLB, 로고와 브랜드 표기는 유지합니다. 수전반은 Incoming switchgear / 受電盤, 저압 배전반은 LV switchboard / 低圧配電盤으로 구분합니다.
- 프로젝트·대지·배치 설비·건물·층·추가 에셋의 이름, 설비 코드, 입력값, 파일명은 사용자 데이터로 보존합니다. 기본 설비 목록의 종류 설명만 번역합니다. 이름을 지정하지 않은 대지의 기본 표시는 번역합니다.
- 도움말의 기존 스크린샷은 한국어 예시로 유지하며, 각 언어의 안내와 캡션을 제공합니다.
- Editor/Monitoring 및 Light/Dark 버튼은 선택 표시만 변경하는 기존 준비 상태입니다.

## 유지보수

`js/locales.js`는 한국어 원문, 영어, 일본어의 사전입니다. 동적 값은 `{0}`처럼 표시하고 번역 순서에 맞게 배치합니다. 이름이 들어가는 값은 다시 번역하지 않습니다.

`js/i18n.js`는 화면의 텍스트와 title / aria-label / placeholder / alt만 변경합니다. 원문을 기억해 한국어로 복원하며, DOM 변경 관찰로 나중에 추가되는 팝업과 오류도 처리합니다. 앱 상태를 다시 만들지 않아 선택·입력 중 내용·카메라를 유지합니다. 서버나 외부 번역 API는 사용하지 않습니다.

새 UI 문구를 추가할 때 사전도 추가합니다. 새 이름 표시 위치는 `data-i18n-skip` 또는 `FEMSI18n.protect(element)`로 보호합니다. 사용자 입력과 같은 문자열이라는 이유만으로 일반 문구를 치환하지 않도록 반드시 검증합니다. 시스템의 대지 표시와 사용자 공간 이름을 혼합한 경로는 `data-i18n-site-path`로 시작 부분만 번역합니다. 브라우저 검증 메시지는 `FEMSI18n.setValidity`로 등록합니다.

## 번역 누락 보완

- 에셋 파일 선택은 기본 파일 입력의 클릭·키보드 기능을 유지하고, 버튼과 미선택 상태만 앱 언어로 표시합니다. 선택한 파일명은 번역하지 않으며, 팝업을 다시 열면 미선택 상태로 돌아갑니다. 운영체제의 파일 탐색 창 자체는 시스템 언어를 따릅니다.
- 필수 입력·숫자·최솟값·최댓값·입력 간격·형식 오류는 앱 언어로 표시하며, 입력 수정과 폼 초기화 시 검사 상태를 해제합니다.
- 일반 설비 배치 완료 알림, 분기점의 연결 설비 수, ID·공간 수치 검사 오류를 보완했습니다. 알려진 필드명 규칙이 고유명사를 보존하는 일반 오류 규칙보다 먼저 적용됩니다.
- 연결선의 분기점 설명과 계통도의 순환 연결 안내는 이름과 별도 요소로 나눕니다. 보호된 영역 안에서도 `data-i18n-ui`로 표시한 시스템 문구만 번역합니다. 계통도의 기본 대지 경로는 툴팁과 접근성 이름에서도 번역하고, 사용자 지정 이름은 유지합니다.

## 검증

- `node --test tests/*.test.cjs`: 번역 사전·이름 보존 및 기존 모델·연결선·저장 기능의 회귀 테스트.
- `node scripts/i18n-browser-server.cjs`: 별도 검증 서버(4182). `/tests/i18n-browser.html`에서 Run language checks를 눌러 반복 전환·입력값·포커스·동적 팝업·오류·설정 저장을 검증합니다.
- `node scripts/i18n-inventory.cjs`: 원문의 점검용 목록을 `output`에 생성합니다. 단순 문자열 추출이므로 동적 문장과 이름을 사람이 구분해야 합니다.
- 프런트엔드 변경 뒤 `node scripts/version-assets.cjs`로 배포 파일 버전을 갱신합니다.

실제 화면에서 세 언어의 설정·도움말·3D·평면도·계통도, 검색, 설비 선택과 입력값 보존을 확인합니다. 모델 드래그·연결선 편집·저장/불러오기는 기존 자동 테스트와 함께 별도 실제 조작 점검 범위로 관리합니다.
