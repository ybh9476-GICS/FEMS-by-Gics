# 대지 속성

좌측 계층에서 대지를 선택하면 우측 패널에 기본 정보와 크기가 나타납니다. 상단 공간 경로에서 대지를 선택해도 같은 패널을 엽니다.

- 이름: Enter로 적용합니다. Esc 또는 다른 곳 클릭은 미적용 이름을 취소합니다.
- 가로·세로: 입력 후 적용을 눌러 함께 변경합니다. 취소·Esc 또는 다른 대상 선택은 미적용 크기를 되돌립니다.
- 면적: 입력한 가로×세로를 m²로 표시합니다. 크기를 적용하기 전에는 입력값의 예상 면적입니다.
- 크기 변경은 기존 대지 중심·설비 좌표·연결선 경로를 유지합니다. 기존 경계 검사를 사용하며 설비나 연결선이 잘리는 축소는 거부합니다.
- 이름과 크기는 각각 한 번의 실행 취소로 복원됩니다. 3D·평면도·계통도에서 같은 대지 정보를 사용합니다.

기존 저장 키와 파일 형식 버전은 유지합니다. 이름을 지정하면 선택 항목 `site.name`에 저장하고, 항목이 없는 기존 파일은 기본 이름인 대지로 표시합니다. 이름을 지원하지 않는 이전 앱에서 다시 저장하면 새 이름은 보존되지 않습니다.

`tests/site-properties.test.cjs`는 이름·파일 왕복 저장·히스토리·편집 이벤트·유효성 검사를, `tests/site-size.test.cjs`는 크기와 경계 검사를 검증합니다.
