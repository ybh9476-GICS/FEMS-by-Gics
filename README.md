# FEMS by Gics

WMS-by-Gics의 독립 실행 방식과 라이브러리·작업 공간·속성 패널 구성을 참고한 FEMS 전용 설비 배치 편집기입니다. 첫 단계는 9종 설비를 배치하고 평면도와 3D에서 확인하는 기능입니다.

## 실행

1. `start-local-editor.cmd`를 더블클릭합니다. Node.js가 필요하며 추가 패키지 설치는 없습니다.
2. 열린 브라우저에서 `http://127.0.0.1:4175/`를 사용합니다. Edge 또는 Chrome을 권장합니다.
3. 서버 창에서 `Ctrl+C`를 누르면 종료됩니다. 포트가 사용 중이면 기존 프로그램을 종료하지 않고 안내 후 멈춥니다.

터미널에서는 `npm run dev`로 실행합니다. 로컬 서버는 이 컴퓨터에서만 접속 가능하며 WMS의 4174번과 다른 4175번 포트를 사용합니다. 수정한 코드는 브라우저 새로고침으로 반영됩니다.

에셋 목록과 GLB를 읽기 위해 HTTP 서버에서 실행하세요. `index.html` 직접 실행(file://)은 추가 에셋을 지원하지 않습니다. 3D에는 WebGL 2를 지원하는 브라우저와 그래픽 환경이 필요합니다. 실행 중 외부 라이브러리 다운로드나 로그인은 없습니다.

## 추가 GLB 설비 등록

하단 목록의 `기본 설비 / 추가 에셋`으로 라이브러리를 전환합니다. 기존 9종 기본 설비와 우측 속성 패널은 그대로 사용합니다.

1. 최신 로컬 서버를 실행합니다. 서버 코드가 바뀐 뒤에는 서버를 한 번 재시작해야 합니다.
2. 하단 `＋ 에셋 등록` → GLB 파일 선택 → 미리보기와 이름·영문명·실제 치수(m)를 확인 → `등록`을 누릅니다.
3. `추가 에셋`의 썸네일을 선택하고 바닥을 클릭합니다. 이동·회전·비율 조절·복제·계층·연결선·실행 취소는 기본 설비와 같습니다.

지원 범위: 텍스처를 내부에 포함한 GLB 2.0, 최대 25 MB, PNG/JPEG 텍스처. Draco·Meshopt·KTX2 압축은 끄고 내보내세요. Unity 스크립트·카메라·조명·애니메이션 재생은 가져오지 않으며, 설비의 정적 모양을 사용합니다. 모델의 가로·세로·높이를 측정해 기본 치수로 제안하고, 바닥 중앙을 피봇으로 맞춥니다. 치수 허용 범위는 기존 설비와 같은 가로/세로 0.2~30 m, 높이 0.2~40 m입니다. 단위가 다른 원본은 등록 창에서 실제 치수를 수정하세요.

등록 시 `assets/equipment/asset-<고유 ID>/model.glb`와 `assets/equipment/index.json`에 저장합니다. 이름이 같아도 별도의 ID가 발급되어 기존 파일을 덮어쓰지 않습니다. 썸네일은 모델에서 자동 생성합니다. 등록 파일을 직접 준비하려면 같은 폴더 규칙으로 GLB를 두고 index.json의 assets 배열에 type, name, en, width, depth, height를 기록하세요. type은 `asset-`로 시작하는 고정 ID이며 경로와 일치해야 합니다.

도면은 기존 type 항목에 에셋 ID를 저장하며 모델 파일 자체는 포함하지 않습니다. 배포하거나 다른 PC로 옮길 때 **도면과 assets/equipment 폴더를 함께 전달**하세요. 정적 호스팅에서는 등록된 에셋의 배치·편집이 가능하고, 새 파일 등록은 로컬 서버에서만 가능합니다. 예전 앱은 추가 에셋 종류를 알지 못하므로 새 버전에서 도면을 여세요. 등록 정보나 모델이 누락되어도 배치·계층·연결선 데이터는 보존하고, 3D에서는 빨간 윤곽 상자로 표시합니다.

## GitHub에 현재 도면 함께 올리기

코드·스타일·기본 도면을 수정한 뒤에는 커밋 전에 `npm run version:assets`를 실행하고 `npm test`로 확인하세요. HTML이 요청하는 파일 주소에 코드 내용으로 계산한 버전을 붙이고, 비동기로 읽는 `app.js`에도 같은 버전을 전달합니다. 새 화면과 캐시된 예전 코드가 섞여 실행되는 문제를 방지하며, 버전 갱신을 빠뜨리면 테스트가 실패합니다. 브라우저에 저장된 작업 도면은 지우지 않습니다.

브라우저 자동 저장은 해당 브라우저에만 남으므로 Git 푸시만으로는 편집한 도면이 전달되지 않습니다. 로컬 서버에서 상단 `기본 도면 교체` → 경고 확인 후 `덮어쓰기`를 누르면 현재 도면이 프로젝트의 `js/default-layout.js`에 바로 저장됩니다. 설비 위치·크기·계층과 연결선 편집 내용이 포함됩니다. 이전 기본 도면은 교체되며 앱의 UNDO로 복원할 수 없습니다. 현재 작업과 브라우저 자동 저장은 유지됩니다. GitHub에 반영하려면 변경된 파일을 별도로 커밋·푸시하세요.

로컬 서버와 정적 호스팅은 같은 기본 파일을 읽지만, 직접 덮어쓰기는 `npm run dev`로 실행한 로컬 서버에서만 가능합니다. 저장 요청은 동일 출처의 JSON만 허용하고 검증한 도면을 지정 파일 하나에 교체합니다. 정적 호스팅에서는 로컬 프로젝트 파일을 수정하지 못합니다. 기존 브라우저의 저장 도면이 기본 파일보다 우선하며, GitHub 저장소 푸시와 사이트 호스팅 활성화는 별개입니다.

## 사용 방법

- 처음 방문하는 브라우저는 프로젝트에 포함된 공유 도면을 엽니다. 현재 기본 도면에는 로컬에서 편집한 설비 10개, 계층 및 연결선 5개의 편집 경로가 포함되어 있습니다. 기존 자동 저장이 있으면 해당 작업을 우선 복원합니다. `새 도면`은 빈 60 × 40 m 부지를 만듭니다.
- 하단 중앙의 설비 썸네일을 선택하고 3D 또는 평면도의 바닥을 클릭합니다. 썸네일에 마우스를 올리거나 키보드로 포커스하면 한글·영문명이 표시됩니다. 0.5 m 간격으로 배치하며 한 번 배치하면 선택 모드로 돌아갑니다. Esc로 취소할 수 있습니다. 좁은 화면에서는 썸네일 목록을 가로로 스크롤합니다.
- 왼쪽에는 현재 배치된 설비가 계층 목록으로 표시됩니다. 이름을 한 줄로 표시하며 행을 선택하면 3D와 속성 패널의 선택이 함께 바뀝니다. 항목 가운데로 드래그하면 하위로 연결하고, 위·아래 가장자리의 삽입선에 놓으면 해당 항목과 같은 단계로 순서를 바꿉니다. 상위 항목 뒤에 넣으면 그 하위 묶음 다음에 배치합니다. 최상위 항목 사이 또는 목록 아래 빈 공간에 놓으면 최상위로 분리됩니다. 자기 자신이나 자신의 하위 설비 안으로는 이동할 수 없습니다. 순서는 기존 설비 배열에 저장되며 코드 검색과 우측 코드 표시는 유지됩니다.
- 계층은 전력 흐름을 정리하기 위한 관계이며 위치·크기를 바꾸지 않습니다. 상위 설비를 이동해도 하위 설비의 좌표는 그대로입니다. 계층 변경은 실행 취소할 수 있고, 상위 설비 삭제 시 직계 하위 설비는 한 단계 위로 올라갑니다. 복제는 선택한 설비 하나만 같은 상위 아래에 만듭니다. 복제 이름은 원본 이름 뒤에 사용하지 않은 번호를 붙입니다. 예: 변압기 → 변압기(1) → 변압기(2). 기존 괄호 번호는 중첩하지 않으며 사용자 지정 이름도 유지합니다. 삼각형으로 접기·펼치기, 이름·코드·설비 종류로 검색할 수 있습니다.
- 좌측 목록에서 `Ctrl+클릭`은 설비 선택 추가·해제, `Shift+클릭`은 기준 항목부터 현재 보이는 목록의 연속 범위 선택, `Ctrl+Shift+클릭`은 기존 선택에 범위를 추가합니다. Mac에서는 Ctrl 대신 Command도 지원합니다. 접힌 하위 항목은 범위에서 제외하고, 검색으로 기준 항목이 숨겨졌다면 클릭한 항목에서 다시 시작합니다. 일반 클릭은 하나만 선택합니다. 여러 설비는 3D·평면도에서도 함께 강조되며 우측에 선택 개수를 표시합니다. 다중 선택 후 Ctrl·Shift 키를 놓고 선택 항목 하나를 드래그하면 함께 계층 이동합니다. 행 가운데는 하위 연결, 행 사이는 같은 단계 삽입, 목록 아래는 최상위 이동입니다. 선택한 항목의 목록 순서를 유지하며, 부모와 자식을 함께 선택하면 내부 계층을 보존합니다. 이동 후 다중 선택을 유지하고 전체 이동은 실행 취소 한 번으로 복원합니다. 선택 상태는 도면 파일과 실행 취소 기록에 저장하지 않습니다.
- 다중 선택의 속성 패널에서는 이름·코드를 `-`로 표시하고 이름 편집과 복제를 비활성화합니다. 위치는 선택 설비의 바닥 외곽을 감싼 영역의 중심이며, 회전은 선택 시작 상태를 0°로 삼아 이 중심 주위로 설비 위치와 각도를 함께 바꿉니다. 크기는 선택 영역의 가로·세로와 최대 높이로 표시하고, 어느 치수를 바꾸든 중심 기준으로 설비 간 간격과 모든 설비 치수를 같은 비율로 조절합니다. 다중 선택에서는 비율 고정이 유지됩니다. 부지 경계나 개별 설비의 크기 제한을 넘으면 전체 변경을 거부합니다. 삭제는 선택한 설비만 제거하고 선택하지 않은 하위 설비는 가장 가까운 남은 상위 설비에 연결합니다. 각 편집·삭제는 실행 취소 한 번으로 복원되며 숫자 편집 중 Esc는 시작 상태로 되돌립니다. 연결선의 설비 접속점은 설비를 따라가고 편집한 중간점·분기점은 부지 좌표에 유지됩니다.
- 배치된 설비나 설비 위 이름표를 클릭하거나 `설비 목록`에서 행을 선택합니다. 3D·평면도 이름표에는 설비 이름만 표시합니다. 이름표 위 드래그와 휠은 기존 화면 이동·확대 동작을 유지하며, 겹친 기즈모는 우선 조작됩니다. 위치·크기·각도는 숫자 입력 또는 드래그 중 즉시 도면과 자동 저장에 반영됩니다. 설비 이름도 입력 즉시 이름표·목록·자동 저장에 반영됩니다. 이름 입력을 마치면 연속 변경이 한 번의 실행 취소로 묶이며, 입력 중 Esc는 시작 이름으로 되돌립니다. 빈 이름은 저장하지 않고 마지막 유효한 이름을 유지합니다.
- 숫자 오른쪽의 `↔` 손잡이를 좌우로 드래그해 값을 조절할 수 있습니다. 위치·크기는 2px당 0.01 m, 회전은 8px당 1°씩 변경되며 입력란의 최소·최대값을 지킵니다. 한 번의 드래그 또는 한 입력란의 연속 편집은 실행 취소 한 번으로 복원됩니다. Esc는 입력 시작 상태로 복원하며, 드래그 중 창을 전환해도 시작 상태로 돌아옵니다. 빈 값·부지 밖 좌표 등 유효하지 않은 입력은 도면에 반영하지 않고 마지막 유효한 값을 유지합니다.
- 설비 크기의 `비율 고정`은 기본으로 체크됩니다. 가로·세로·높이 중 하나를 입력하거나 드래그하면 편집 시작 시점의 비율로 세 치수가 함께 바뀝니다. 체크를 해제하면 각 치수를 따로 조절합니다. 어느 한 치수라도 크기 제한이나 부지 경계를 넘으면 변경 전체를 거부하고 마지막 유효한 크기를 유지합니다. 체크 상태는 현재 창에서 유지되며 새로 열면 기본 체크 상태로 시작합니다.
- 3D·평면도에서 설비를 선택하면 객체 바닥 중심(Y=0)을 피봇으로 하는 빨간 X축·파란 Z축 이동 기즈모가 나타납니다. 화살표를 좌클릭 드래그하여 해당 축만 0.01 m 단위로 이동할 수 있습니다. 객체의 회전 각도와 관계없이 우측 패널과 동일한 부지 좌표축을 사용하며, 이동 중 패널 좌표·목록·자동 저장이 함께 갱신됩니다. 부지 밖으로 이동하지 않으며, Esc·포인터 취소·창 전환 시 시작 위치로 복원합니다. 한 번의 드래그는 실행 취소 한 번으로 복원됩니다. 설비 옆의 `↻ 90°` 버튼으로 모드 전환 없이 회전할 수 있습니다. 배치 모드·선택 해제 시 이동·회전 기즈모를 숨기고, 화살표와 연결선이 겹치면 화살표 조작을 우선합니다.
- `↻ 90°` 또는 R로 회전합니다. 복제·삭제·새 도면·파일 열기는 실행 취소로 되돌릴 수 있습니다.
- 3D·평면도 모두 좌클릭 드래그는 화면 이동, 휠은 확대·축소입니다. 우클릭 드래그 회전은 3D에서만 지원하며, 평면도는 방향을 고정하고 우클릭을 무시합니다. 창 크기를 바꾼 뒤 `전체 보기`를 누르면 화면 위치·회전·배율을 다시 맞춥니다.
- 모델의 바닥 영역이 겹치면 하단에 표시합니다. 경계 접촉은 겹침으로 보지 않습니다. 부지 밖 배치는 거부하며 드래그 시 부지 안으로 제한합니다.
- 도면당 최대 300개 설비를 지원합니다. 화면이 좁으면 모델 이름이 겹칠 수 있어 `이름 표시`를 끄거나 확대하여 확인하세요. 정밀 편집은 데스크톱 화면을 권장합니다.

단축키: `Ctrl+Z` 실행 취소, `Ctrl+Shift+Z` 또는 `Ctrl+Y` 다시 실행, `Ctrl+S` 저장, `Delete` 선택 설비 삭제, `R` 회전, `F` 전체 보기, `/` 검색. 입력 중에는 편집기 단축키가 작동하지 않습니다.

## 전력 흐름 연결선

- 부모·자식 관계를 만들면 바닥 기준의 연결선이 자동으로 생기고, 관계를 해제하면 사라집니다. 기본 지름은 0.2 m, 색상은 파랑입니다. 3D와 평면도에서 부모 → 자식 방향으로 점선이 계속 흐릅니다.
- 자동 경로는 X·Z 방향의 직선과 직각으로 잇습니다. 같은 부모에서 출발하여 겹치는 앞쪽 구간은 **공통 연결선 하나**로 합치고, 실제 갈라지는 위치에 공유 분기점을 만듭니다. 분기 이후 단순히 교차하는 선은 서로 연결하지 않습니다. 초기 접속점은 설비의 바닥 중심입니다. 부모의 위·아래로 향하는 자식은 각각 위·아래로 출발하므로 공통 구간을 억지로 만들지 않습니다. 기존에 직접 편집한 경로는 변환할 때 유지합니다.
- 공유 분기점을 드래그하거나 X·Z 좌표를 바꾸면 공통 구간과 연결된 모든 가지가 함께 따라옵니다. 인접한 코너도 함께 조정하여 직각을 유지합니다. 분기점 자체를 삭제하면 여러 가지가 끊어질 수 있으므로 삭제는 막고, 가지 위의 일반 코너는 삭제할 수 있습니다. 일반 코너를 삭제하거나 최단 경로로 복원해도 해당 가지는 실제 분기점에서 출발합니다.
- 3D·평면도에서는 선택된 최상위 부모의 연결망에만 포인트를 표시합니다. 다른 연결망은 선분을 클릭해 편집 대상으로 전환합니다. 우측 패널과 복원 경고에 대상 부모 이름을 표시합니다.
- 3D·평면도에서 선분을 클릭하면 우측 연결선 속성이 열리고 지름·선택 선분 색상을 수정할 수 있습니다. 두 보기 모두 흰색 포인트의 X·Z 이동, 중앙 손잡이의 선분 이동·코너 추가, 포인트 추가·삭제·최적화·최단 경로 복원을 지원합니다. 검은색 설비 접속점은 고정되며, 손잡이 드래그 중에는 카메라가 움직이지 않습니다. 지름은 선택한 연결 구간(설비 접속점·분기점 사이)에 적용되고, 색상은 선택한 선분에만 적용됩니다. 공통 구간의 색상과 경로는 한 번만 편집합니다. 연결선은 조명·명암 없이 팔레트 원색으로 출력하며, 화면용 sRGB 변환을 적용합니다. 원색 80%·흰색 20%의 반복 점선으로 부모→자식 흐름을 표시하고 선택 강조는 외곽 회색 테두리로 구분합니다. 포인트를 선택한 동안 색상 팔레트는 비활성화됩니다. 편집 결과는 자동 저장·도면 파일·기본 도면 교체에 포함됩니다.
- 포인트 추가·코너 추가로 나뉜 구간과 설비 이동에 따라 보완된 직각 구간은 원래 선분 색상을 이어받습니다. 색상이 다른 선분 사이의 포인트를 직접 삭제하면 합쳐지는 구간은 부모 쪽 색상을 사용합니다. 드래그 후 자동 정리는 실제 색상 경계를 유지합니다. 명시적인 포인트 최적화는 경고 확인 후 색상 경계도 제거하고 부모 쪽 색상으로 합칩니다. 최적화는 소수점 계산 오차가 있는 직선점과 길이가 0인 중복 구간도 정리하며, 패널에 제거 개수 또는 남겨 두는 이유를 표시합니다. 최단 경로 복원은 색상 순서와 길이 비율을 새 경로에 옮기며, 색상 경계에는 직선 위 포인트가 남을 수 있습니다.
- 시작·끝·꺾임점에 원형 포인트가 표시됩니다. 설비 연결 끝점은 검은색이며 이동·좌표 편집·삭제를 막습니다. 흰색 중간 포인트는 드래그하거나 X·Z를 입력한 위치로 이동하며, 양 끝 고정점을 유지하면서 직각 연결선을 자동 완성합니다. 기존 포인트로 연결할 수 있으면 수를 유지하고, L자 코너처럼 이동 여유가 없으면 필요한 꺾임점을 자동 보완합니다. 한 드래그 중에는 시작 경로를 기준으로 계산하여 꺾임점이 계속 누적되지 않습니다. 선택 우선순위는 기즈모 → 흰색 포인트 → 설비 → 연결선입니다. 흰색 포인트는 화면 기준 반경 6px 안에서 선택되며 검은색 고정점·선분은 설비 선택보다 뒤입니다. Alt+클릭은 기즈모나 포인트가 겹쳐도 설비를 먼저 선택합니다. 마우스를 올리면 흰색 포인트는 청록색 테두리, 설비는 주황색 윤곽선, 선분은 청록색 테두리로 선택 대상을 보여줍니다. 클릭한 선분은 해당 구간에만 굵은 밝은 회색·흰색 테두리와 양 끝 회색 원을 표시합니다. 중앙의 원래 색상과 점선 흐름은 유지됩니다.
- 선분 선택 → `선분에 포인트 추가`로 중간에 포인트를 추가합니다. 일반 포인트 선택 → `선택 포인트 삭제` 또는 Delete로 삭제합니다. 직각 유지에 필요한 꺾임은 자동 보정되므로, 꺾임 삭제 시 다른 위치에 꺾임이 생길 수 있습니다. 검은색 설비 접속점과 공유 분기점은 삭제할 수 없습니다.
- 포인트 이동은 양옆의 인접 코너까지만 조정하며 먼 경로를 유지합니다. 이 범위에서 기존 포인트로 연결할 수 없는 경우에만 필요한 코너를 보완합니다. 선분을 선택하면 중앙에 네모 이동 손잡이가 나타납니다. 가로 선분은 상하, 세로 선분은 좌우로 이동하며 검은색 양 끝점은 유지합니다. 화면에서 24px 이하인 짧은 선분은 확대하면 손잡이가 나타납니다. 네모 손잡이도 일반 선분과 달리 설비보다 우선 선택되며 Alt+클릭으로 설비를 선택할 수 있습니다.
- `코너 추가`를 누른 뒤 초록 네모를 드래그하면 선택 선분의 가운데 1/3 구간을 직각으로 돌출시키는 경로가 실시간 미리보기됩니다. 놓으면 확정, Esc로 취소합니다. 기존 `선분에 포인트 추가`도 유지합니다. 선분의 손잡이 밖이나 빈 공간 드래그는 기존 화면 이동입니다.
- 포인트·선분 드래그 시 같은 부모에 속한 공통 구간·가지의 포인트와 6px 이내로 정렬되면 청록 안내선을 표시합니다. 붙은 정렬은 9px 이상 벗어나면 해제되며 Shift를 누르면 정렬 보조를 일시 해제합니다. 좌표 정렬만으로 서로 다른 분기점을 합치지는 않습니다. 이동 후 이번 드래그에서 생성된 중복·직선 보조점만 정리하고, 기존 수동 포인트는 유지합니다.
- 편집한 중간 포인트와 분기점은 부지 좌표에 유지되고, 검은색 접속점은 연결 설비를 따라갑니다. 중간 포인트는 분기점·설비 사이 연결 구간당 최대 64개입니다. `최단 경로 복원`은 경고 팝업에서 복원을 확인한 뒤 선택한 최상위 부모에 속한 연결망 전체(하위 부모의 연결선 포함)를 복원합니다. 공유 분기점과 설비 접속점 사이의 각 구간을 최단 직각으로 잇고, 다른 최상위 부모의 연결선은 변경하지 않습니다. 공유 분기점·설비 접속점·색상·지름은 유지합니다. 취소 또는 Esc는 현재 경로를 유지합니다.
- `포인트 최적화`는 색상 변경 가능성을 알리는 경고 팝업에서 확인한 뒤, 선택한 연결 구간의 직선 위 불필요한 중간점과 연속 중복점을 색상 구분 없이 제거합니다. 합쳐지는 선분에는 부모 쪽 색상이 남고, 길이가 없는 구간의 색상은 제거합니다. 경로 모양·코너·되꺾임·분기점·양 끝 고정점·지름을 유지하며, 실행 취소 한 번으로 포인트와 색상을 복원합니다. 정리할 점이 없으면 도면과 실행 취소 기록을 변경하지 않습니다.
- 숫자 연속 입력과 포인트 한 번의 드래그는 각각 실행 취소 한 번으로 복원합니다. Esc·포인터 취소·창 전환으로 포인트 드래그를 취소할 수 있습니다. 부모를 바꾸면 해당 설비의 기존 연결선 편집은 초기화됩니다.

## 저장과 호환성

브라우저 자동 저장은 `gics-fems-workspace-v1`을 사용합니다. WMS 데이터·원격 저장소·브라우저 저장 이름을 복사하지 않습니다. 자동 저장 실패 또는 손상된 저장 내용은 화면에 안내하며, 읽지 못한 기존 내용을 자동으로 덮어쓰지 않습니다.

`도면 저장`을 누를 때마다 파일 이름과 저장 위치 선택을 요청합니다. 파일은 FEMS 전용 JSON 형식인 `.fems`로 저장합니다. 취소하면 기록하지 않습니다. 시스템 저장창 미지원 브라우저에서는 Edge 또는 Chrome 사용을 안내하며 자동 다운로드로 대체하지 않습니다.

`열기`로 2 MB 이하의 FEMS v1·v2 도면을 가져옵니다. v1은 검증 후 공유 분기 구조인 v2로 변환하며 원본 파일은 수정하지 않습니다. 잘못된 파일·지원하지 않는 버전·중복 코드·부지 밖 설비는 거부합니다. WMS의 `.gics`·`.tbl` 파일은 지원하지 않습니다.

계층 관계는 설비의 선택 항목 `parentId`(상위 설비 ID)에 저장하며 자동 저장과 도면 파일에 함께 포함됩니다. 기존 v1 도면은 위치·크기를 유지하면서 모두 최상위 설비로 불러옵니다. 없는 상위 설비나 순환 관계가 있는 파일은 거부합니다. 계층을 지원하지 않는 예전 앱에서 다시 저장하면 계층 정보가 사라질 수 있습니다.

v2의 `networks`에는 부모별 접속점·분기점(`nodes`)과 그 사이의 공통 구간·가지(`edges`)를 저장합니다. 여러 가지가 같은 분기점 ID를 참조하므로 공통 경로·색상·지름을 중복 저장하지 않습니다. 기존 v1의 `connection`·`junction`은 변환 원본으로 남기며 v2 화면은 `networks`를 사용합니다. 예전 앱은 v2 파일을 편집할 수 없습니다.

기존 브라우저 작업을 처음 변환할 때 `gics-fems-workspace-v1-before-shared-branches`에 변환 전 원문을 먼저 백업합니다. 백업이나 변환본 저장에 실패하면 기존 도면을 유지하고 자동 저장을 중지합니다. 백업은 상단 `기본 도면 교체` 팝업의 `공유 분기점 변환 전 도면 백업 내려받기`에서 받을 수 있으며, 내려받을 때 기본 파일을 덮어쓸 필요는 없습니다. 이전 백업과 다른 v1 작업을 다시 변환하면 이전 백업도 날짜가 붙은 별도 키로 보존합니다. 겹쳤던 선의 색상·지름이 다르면 기존 화면에서 나중에 그려지던 선의 값을 공통 구간에 사용합니다. 기존 설비의 위치·크기·계층과 편집 경로는 유지합니다.

자동 저장은 같은 브라우저의 같은 주소에서만 복원됩니다. HTML 직접 실행, localhost, 127.0.0.1은 서로 다른 저장 공간일 수 있습니다. 브라우저 데이터를 지우기 전 중요한 도면은 파일로 보관하세요. 실행 취소 기록은 현재 창에서 최근 60회이며 새로고침하면 초기화됩니다. 한 도면은 한 창에서 편집하는 것을 권장합니다.

GitHub 저장소 생성·커밋·푸시·배포는 수행하지 않았습니다. 향후 정적 호스팅에서는 상대 경로로 앱을 제공할 수 있으나, HTTPS 및 브라우저의 저장창 지원 여부를 별도로 확인해야 합니다.
